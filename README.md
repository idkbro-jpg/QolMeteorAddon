# QolMeteorAddon

Meteor Client QoL Addon — Low health toasts, totem counter and other quality-of-life modules.

## Requirements

- Minecraft (version matching the template, currently 26.3)
- Fabric Loader
- Meteor Client

## Building

```bash
./gradlew build
```

The jar will be in `build/libs/`.
Put it in your `.minecraft/mods` folder next to Meteor Client.

## Development

This project is based on the official [Meteor Addon Template](https://github.com/MeteorDevelopment/meteor-addon-template).

## Features (planned / in progress)

- Low health toast / notification
- Totem count HUD / module
- More QoL modules coming soon
